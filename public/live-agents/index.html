BINANCE AGENT OS

Where CIRCUIT fits.

A worker AI agent proposes an action. CIRCUIT evaluates it against the active Financial Mandate and runtime state. Only a separate, explicitly configured execution adapter can act after an ALLOW/RESIZE verdict.

AI Agent→CIRCUIT→Execution Adapter→Binance Agent OS

HOW TO USE IT

Connect a live agent in four controlled steps.

  1. 01
    Connect the AI host to CIRCUIT MCP.

    Use the hosted or self-managed `/mcp/circuit` endpoint so the agent can inspect status and submit typed intents.

  2. 02
    Activate a Financial Mandate out of band.

    Natural-language compilation produces DRAFT policy only. Explicit user activation creates the operating envelope.

  3. 03
    Discover and map authenticated Binance Agent OS capabilities.

    Do not guess tool names or schemas. Confirm the authenticated tool surface and map evidence/execution capabilities explicitly.

  4. 04
    Keep execution behind the CIRCUIT verdict boundary.

    BLOCK, REVIEW, and PAUSE never cross into execution. Recovery remains explicit after the cause is understood.
